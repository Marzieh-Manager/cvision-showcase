# CVision: my part of a team CV app

**[CVision](https://github.com/Ali-Paybarjay/CVision)** tailors a UK CV and cover letter to any job ad, without inventing anything.
Live: https://cvision-eta.vercel.app

A four-person team project, built in October and November 2026, with each of us coding with Claude Code. This repository shows my part of the project. The code is in the team's repository, linked above.

**My role: product manager, team coordinator and developer.**

### Product and team

- Owned the product, the user experience and the final presentation, and ran the team's coordination: daily calls, the project board and milestone reports.
- Before each milestone, went through the app on a phone as a new user would, and turned each problem into a GitHub issue with a clear owner (43 issues).
- Set the priority of every feedback card: fix now, fix before the feature freeze, or wait for phase 2.
- Made the product and UX decisions, such as the fixed section headings of the tailored UK CV.
- Lead reviewer: reviewed 50 pull requests and approved 47, more than anyone else on the team.
- Held one-to-one sessions with each team member to talk through my feedback and review comments.
- Wrote the story and the timed script for the live demo.

### What I built (32 merged pull requests)

- **CV check:** anyone can see in about two minutes, without signing up, whether their CV is ready for a UK employer.
- **Interview practice:** a text practice interview for the user's own job ad, on phone and desktop, one question at a time, with a full feedback report. For questions the user skipped, it suggests an answer built only from their own CV.
- **Tailored CV:** questions about the user's own work to fill gaps, "Make it stronger" suggestions that never add claims the user did not make, and a final check before download.
- **Clearer waits:** the first interview question is ready about 25 seconds sooner, and each wait says what is happening and how long it takes.
- Worked on the AI evals for the interview engine.

**Stack:** Next.js, React, TypeScript, Supabase (Postgres), Tailwind CSS, Claude API, Vitest, Playwright, Vercel
